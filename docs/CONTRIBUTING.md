# 🤝 Guia de Contribuição

Obrigado pelo seu interesse em contribuir para este pacote do ecossistema **Nhonguista**! Sendo este um módulo **Open Source** (Apache License 2.0), encorajamos vivamente a participação da comunidade.

## 🚀 Como Contribuir

1. Faça um Fork deste repositório.
2. Crie uma branch a partir da `main` (ou `devlab` para novas funcionalidades).
3. Escreva os seus commits em Inglês, seguindo o padrão **Conventional Commits** (ex: `feat: add new feature`).
4. Faça push para a sua branch e abra um Pull Request (PR).

## 📏 Padrões de Código
- **Idiomas:** Código, variáveis e mensagens de commit **sempre em Inglês**. Documentação e PRs em **Português**.
- Siga as regras de linting do projeto.

Ao contribuir, concorda com o nosso [Código de Conduta](CODE_OF_CONDUCT.md).
