# 🛡️ Política de Segurança

A segurança é uma prioridade absoluta para a ZEDECK'S IT e para o ecossistema Nhonguista.

## 🕵️ Como Reportar uma Vulnerabilidade

> **POR FAVOR, NÃO ABRA UMA ISSUE PÚBLICA PARA REPORTAR VULNERABILIDADES CRÍTICAS.**

Se descobrir uma vulnerabilidade de segurança neste pacote, pedimos que a reporte de forma confidencial.

1. Envie um e-mail detalhado para: **security@nhonguista.com**.
2. Inclua uma descrição clara da vulnerabilidade e os passos para a reproduzir.

Garantimos a receção e a primeira avaliação do seu reporte num prazo máximo de **48 horas**.
