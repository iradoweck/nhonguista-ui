# Nhonguista Landing — Institucional e SEO

A porta de entrada do ecossistema. Focada em apresentar a proposta de valor do **Nhonguista**, capturar leads e converter visitantes em utilizadores e profissionais.

---

## 🚀 Tecnologias
- **Framework:** Next.js 15 (SSR para SEO)
- **Styling:** TailwindCSS v3
- **Componentes:** @nhonguista/ui
- **Performance:** Otimização de imagens e Core Web Vitals.

---

## 🛠️ Início Rápido
Este app faz parte de um Monorepo. Para rodar:

```bash
# Na raiz do monorepo
pnpm dev --filter landing
```

---

## 🎯 Objetivo
- **Marketing:** Divulgar o lançamento em Nampula.
- **SEO:** Ranqueamento para serviços em Moçambique.
- **Conversão:** Call-to-actions claros para o Portal Web e App Mobile.
