# Nhonguista Admin — Gestão Central

Painel administrativo restrito para a gestão do ecossistema **Nhonguista**. Permite o controle de usuários, verificação de profissionais e monitoramento de atividades.

---

## 🚀 Tecnologias
- **Framework:** Next.js 15
- **Styling:** TailwindCSS v3
- **Componentes:** @nhonguista/ui
- **Segurança:** Autenticação via Laravel Sanctum (Admin Role required)

---

## 🛠️ Início Rápido
Este app faz parte de um Monorepo. Para rodar:

```bash
# Na raiz do monorepo
pnpm dev --filter admin
```

---

## 🔐 Acesso
O acesso é restrito a utilizadores com permissões administrativas configuradas no Backend.
