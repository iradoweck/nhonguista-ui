# Política de Segurança do Nhonguista

A segurança da nossa plataforma e dos dados dos cidadãos de Nampula é a nossa principal prioridade. Nós da **Irmãos Muacigarro & ZEDECK'S IT** levamos as vulnerabilidades extremamente a sério.

## Versões Suportadas

Apenas as versões mais recentes (listadas abaixo) recebem suporte e patches de segurança ativamente.

| Versão | Suportada          |
| -------| ------------------ |
| v0.1.x | :white_check_mark: |
| Antigas| :x:                |

## Como Reportar uma Vulnerabilidade (IMPORTANTE)

**NÃO crie uma "Issue" pública no GitHub para reportar vulnerabilidades de segurança.**

Se você encontrou alguma falha crítica (ex: Injeções SQL, falhas no Laravel Sanctum, vazamento de Tokens, bypass de Auth no Painel de Admin), por favor, reporte o problema **diretamente para a equipe de desenvolvimento** de forma privada.

1. **Evite a divulgação pública** até que tenhamos tido a oportunidade de investigar e corrigir o problema.
2. Forneça o máximo de informações possível: o tipo de vulnerabilidade, passos para reproduzir, e qualquer código relevante.

Nós confirmaremos a receção do seu relato o mais rápido possível e o manteremos atualizado sobre o nosso progresso na mitigação da vulnerabilidade.

Agradecemos o seu esforço em ajudar a manter a plataforma Nhonguista segura para toda a comunidade!
